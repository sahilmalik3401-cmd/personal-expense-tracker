# Personal Expense Tracker

## About
This is a beginner-friendly Python project
to manage personal expenses.

## Features
- Add new expenses
- View all expenses
- Calculate total expenses
- Show category-wise expenses
- Store data in a CSV file

## Technologies Used
- Python
- CSV
- Basic file handling

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run: python main.py
